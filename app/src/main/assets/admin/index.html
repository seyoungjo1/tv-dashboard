TV 대시보드 관리

관리자 로그인

초기 비밀번호는 TV 화면의 ⚙ 설정 → '관리자 비밀번호'에 표시됩니다.
여기에 파일을 끌어다 놓으면 현재 폴더에 업로드됩니다. (같은 이름은 교체)
이름크기수정 시각
메뉴 규칙 — 자료 폴더 바로 아래의 폴더 1개가 TV 왼쪽 버튼 1개가 됩니다. 버튼 이름 = 폴더명(앞의 정렬 번호 01_ 등은 숨김), 아이콘 = 폴더 안 icon.png (icon.jpg / icon.webp 도 가능, 정사각형 권장, 없으면 이름 첫 글자 색상 타일). 버튼을 누르면 폴더의 index.html이 오른쪽에 표시됩니다.
상단 로고를 바꾸려면 자료 폴더 루트에 logo.png 를 올리세요.
대기 화면 동영상은 자료 폴더 루트에 mp4 등의 동영상을 올리면 됩니다. '.' 또는 '_' 로 시작하는 폴더는 메뉴에 나오지 않습니다.

APK 업로드로 업데이트

GitHub Releases 에서 받은 서명된 APK 를 여기서 올리면 TV 에 설치 확인 창이 뜹니다. TV 앞에서 '설치' → Android 설치 화면에서 '업데이트'를 눌러야 설치됩니다 (무인 자동 설치는 Android 정책상 불가). 자료와 설정은 유지되며, 설치를 취소하거나 실패해도 기존 버전을 계속 사용합니다.

또는 TV 의 ⚙ 설정 → 업데이트 확인 을 누르면 업데이트 주소(update.json)에서 새 버전을 확인해 내려받습니다.

PC 프로그램에서 JSON 주기 업로드

모든 요청에 Authorization: Bearer <API 토큰> 헤더가 필요합니다. 업로드는 임시 파일에 저장된 뒤 완료 시 한 번에 교체되므로 TV 화면에 불완전한 파일이 보이지 않습니다.

curl (Windows 10+ 기본 포함) 

      PowerShell
      

      API 목록
      
GET    /api/status                      상태
GET    /api/menu                        TV 메뉴 구성
GET    /api/list?path=폴더               목록
GET    /api/file?path=폴더/파일          다운로드
PUT    /api/file?path=폴더/파일          업로드/교체 (본문 = 파일 내용, &overwrite=0 이면 덮어쓰기 금지)
DELETE /api/file?path=경로[&recursive=1]  삭제
POST   /api/mkdir?path=폴더              폴더 생성
POST   /api/rename?path=원래경로&to=새경로  이름 변경/이동
POST   /api/reload                      TV 화면 새로고침
GET|PUT /api/settings                   설정 (JSON)
PUT    /api/update/apk                  APK 업로드 (TV 에서 설치 승인)
