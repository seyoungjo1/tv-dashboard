# TV 대시보드 원격 관리 (PC 프로그램)

다른 공유기·다른 망에 있는 PC 에서 TV(대상 오산공장 Dashboard 앱)에 폴더·파일·설정·앱 업데이트를 보냅니다.
Tailscale 같은 별도 앱 없이, **GitHub 공개 레포를 우체통으로만** 씁니다.

```
PC (tvrun.bat → 브라우저 화면)  ──암호화된 작업──▶  GitHub 중계 레포  ◀── TV 앱이 10초마다 확인해서 가져감
                                                   (TV 가 가져가면 즉시 삭제)        자료는 TV 에만 저장
```

- 모든 내용(파일·파일명·설정·목록)은 **AES-256-GCM 으로 암호화**되어 지나갑니다. 공개 레포여도 내용은 보이지 않습니다.
- 암호키는 처음 설정할 때 **자동으로 만들어져 이 폴더의 `tvrelay.json` 에만** 저장됩니다(레포에 올라가지 않음).
- 반영까지 TV 확인 주기(기본 10초)만큼 걸립니다. TV 가 꺼져 있으면 켜졌을 때 처리됩니다.

## 처음 한 번 설정 (TV 에서는 할 것이 없습니다)

1. **중계 레포 만들기** — GitHub 에서 New repository → 이름 `tv-dashboard-relay`, **Public**, **Add a README file** 체크 → Create
2. **토큰 만들기** — https://github.com/settings/personal-access-tokens/new
   (프로필 사진 → Settings → 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens)
   - Repository access: **Only select repositories** → `tv-dashboard-relay`
   - Permissions → Repository permissions → **Contents: Read and write**
3. **PC** — Python 3.9 이상 설치("Add python.exe to PATH" 체크) → 이 폴더의 `tvrun.bat` 실행 → 화면의 [1. GitHub 토큰]에 붙여넣기 → 저장
   (암호키는 자동으로 만들어져 `tvrelay.json` 에 저장됩니다. 설치할 라이브러리도 없습니다 — Windows 내장 암호화 사용)
4. **TV 연결** — TV 앱 화면(자료가 없을 때 안내 화면) 또는 TV ⚙ 설정 → 원격 중계 → **연결 코드**(예: `K7QM-4PXD`)를 보고
   PC 화면의 [2. TV 연결]에 입력 → 15초쯤 뒤 "TV 연결 완료"
   - PC 는 연결 정보(레포·암호키·토큰)를 **그 코드로 암호화**해 레포에 잠깐 올리고, TV 가 토큰 없이 읽어 가져간 뒤 바로 지웁니다.
   - 코드를 모르면 풀 수 없습니다. 다시 연결하려면 TV ⚙ 설정 → **원격 연결 초기화** 후 새 코드로 연결하세요.

> `tvrelay.json` 에는 암호키와 토큰이 들어 있습니다. 이 파일을 가진 사람은 TV 를 관리할 수 있으니 공유하지 마세요.

## 사용

- **tvrun.bat** — 화면 열기. 실행할 때마다 프로그램을 자동으로 최신 버전으로 업데이트합니다.
  - 화면이 켜져 있는 동안에는 오른쪽 위 **[프로그램 업데이트]** 를 누르면 새 버전을 받고, 검은 창을 끄지 않아도 화면이
    새 버전으로 저절로 다시 시작·새로고침됩니다 (s4bridge 와 같은 방식: 검은 창이 감시자, 화면은 그 자식).
  - 업데이트 확인은 캐시합니다: 10분 안에 확인했으면 GitHub 에 묻지 않고, 그 뒤에도 바뀐 것이 없으면 짧은 확인 1번(304)으로 끝냅니다.
    TV 상태도 마지막 상태를 저장해 두었다가 화면을 켜면 바로 보여 주고, 계속 묻지 않습니다(작업 완료·⟳·창으로 돌아왔을 때만 확인).
  - 업데이트는 레포의 커밋을 고정해서 받고, 받기 전에 `backup/<시각>/` 에 백업하며, 실패하면 기존 버전을 그대로 씁니다.
  - **파일 탐색기**: 왼쪽 = TV 폴더 트리(☰ 로 숨기기/열기). PC 탐색기에서 파일·폴더를 **폴더 위에 끌어다 놓으면** 그 폴더로 올라갑니다.
    오른쪽 = **미리보기** — 폴더를 고르면 그 폴더의 index.html 을 TV 와 똑같이 띄우고, 이미지·동영상·JSON·텍스트도 바로 봅니다
    (TV 에서 받아 오는 데 10~20초, 방금 올린 파일은 즉시). 폴더 만들기·이름 변경·삭제·교체·다운로드·예제 대시보드 만들기
  - TV 설정: 상단 제목, 대기 화면(멘트·시간·소리), 자동 새로고침, PIN 등
  - 앱 업데이트: 서명된 APK 를 보내면 TV 화면에 설치 확인 창 → TV 앞에서 승인
- **tvupload.bat** — 작업 스케줄러용 무인 업로드
  ```
  tvupload.bat C:\data\생산팀\data.json 01_생산팀/data.json
  ```
  TV 에 반영되면 종료 코드 0, 기록은 `out\upload.log`. (TV 가 꺼져 있으면 3분 기다린 뒤 코드 3 — 작업은 TV 가 켜지면 처리됩니다)
- **바뀐 파일만 올리기** — TV 가 파일마다 버전(SHA-256)을 알려 주므로, 화면에서 끌어다 놓거나 자동 업로드할 때
  TV 와 내용이 같은 파일은 건너뛰고 바뀐 파일만 보냅니다 (작업 목록에 "바뀌지 않은 n개 건너뜀" 표시).

## TV 여러 대 관리

- GitHub 토큰·암호 열쇠는 같이 쓰고, **TV 마다 이름(우편함)만 다르게** 합니다. 화면 맨 위의 TV 이름 칸에서 골라 관리합니다
- **[+ TV 추가]**(위쪽 TV 칸 또는 [연결] 탭) → 새 이름 → 그 TV 화면의 연결 코드 입력. 기존 TV 연결은 그대로 둔 채 한 대가 늘어납니다
- 미리보기 보관함 · 보낸 버전 · 직원용 도구 · 백업은 TV 마다 따로 기록됩니다 (`out/tv/<TV 이름>/`, `grants.json`, `tv-backup/<TV 이름>/`)
- **자동 업로드 .bat 은 만들 때 고른 TV 로** 올립니다 (파일 이름에 TV 이름이 붙음). 예전에 만든 .bat 은 처음 연결한 TV 로 올라갑니다
- **두 TV 에 같은 이름을 쓰면 안 됩니다** — 작업을 먼저 가져간 한 대에만 반영됩니다
- 같은 화면으로 쓸 TV 는 [연결] 탭의 백업에서 [⬆ 백업 파일 보내기] 로 다른 TV 의 구성을 그대로 복사할 수 있습니다

## 전송 결과

- 보내면 화면 아래에 '보냈습니다' 알림이 잠깐 뜨고 끝입니다 (자동 업로드 .bat 처럼). 작업은 GitHub 에 암호화되어 맡겨지고 TV 가 가져가 반영합니다
- 결과는 파일 탐색기 **아래쪽 [전송 결과]** (옆 [기록] = 프로그램 기록, ▾ 로 접기): **보냄**(TV 가 아직 가져가지 않음, TV 가 꺼져 있어도 켜지면 반영) · **반영됨** · **실패**. 실패가 있으면 탭에 빨간 숫자
- 기록은 TV 별로 이 PC 에 남고, 화면을 다시 열면 아직 '보냄' 인 작업의 결과를 이어서 확인합니다

## TV 백업 · 새 TV 로 옮기기

- 이 PC 에서 올린 것(화면 · tvupload.bat · 자동 업로드 .bat)과 삭제 · 이름 변경 · 화면보호기 · 메뉴 순서 · TV 설정은
  **TV 이름별로 자동 백업**됩니다 → `tv-backup/<TV 이름>/` (따로 누를 것 없음)
- **[⬇ 백업 파일 넣기]** (지금 TV → 이 PC 백업): 직원 도구·TV 에서 고친 것까지 TV 의 파일·설정을 받아 백업에 넣습니다 (바뀐 것만)
- **[⬆ 백업 파일 보내기 → TV 이름]** (그 백업 → 지금 TV): 백업 목록의 줄마다 있는 버튼. 파일(같은 것은 건너뜀) · TV 설정 ·
  직원용 업로드/공지 도구(같은 열쇠 — 나눠 준 HTML 그대로 동작)까지 보냅니다. 중간에 끊기면 다시 누르면 이어서
- **새 TV 연결**: 연결 코드로 붙이면 "이 백업 파일을 보낼까요?" 라고 묻습니다. **다른 TV 의 백업**을 골라 보낼 수도 있습니다 (예: 1공장 TV → 새 2공장 TV)

## TV 왼쪽 메뉴 순서

- 오른쪽 **TV 화면 미리보기**의 왼쪽 아이콘을 **끌어다 놓아** 순서를 바꾸고 **[순서 저장]** → TV 에 바로 반영 (`자료/메뉴순서.txt`)

## 화면보호기 (TV 의 main 폴더)

- 파일 탐색기에서 `main` 폴더를 고르면 오른쪽 TV 모니터가 **화면보호기 미리보기**로 바뀌고, 그 아래에 **화면보호기 설정**이 나옵니다
  - 미리보기: TV 와 똑같은 화면보호기를 TV 의 실제 자료로 보여 주고, 고친 공지·동영상 목록은 저장 전에도 바로 반영
  - **공지사항**: 한 줄에 하나 (5개까지 표시) → `main/공지.txt`
  - **동영상**: [+ 동영상 추가] · [+ 유튜브 링크 추가](쇼츠 포함) · ▲▼ 순서 · ✕ 삭제 → [TV 에 저장]
  - **동영상 미리보기**: 미리보기 화면에서 목록 순서대로 재생 (새로 추가한 파일·유튜브는 바로, TV 에만 있는 영상은 줄의 ▶ 를 누르면 받아 와서 재생 — 한 번 받으면 다음부터 바로)
  - **영상마다 표시 방식**: **크롭**(긴 쪽을 자름 · 위쪽/가운데/아래쪽 맞춤) · **확장**(전체가 보이고 남는 곳은 블러/단색 + 색) ·
    **직접 조절**(크롭=100% 또는 확장=100% 기준으로 크기 %, 가로/세로 기준선에서 px — 음수 가능. 기준을 바꾸면 위치가 그대로이도록 px 가 자동 환산,
    예: 아래쪽 기준 0 → 위쪽 기준 -300) → `main/설정.json` 재생 목록
  - **사진**: [+ 동영상·사진 추가] 로 jpg · png · webp · gif 도 목록에 넣을 수 있습니다. 사진마다 **보여 줄 시간(초)** 과 **전환 효과**
    (모핑 · 쉐이딩 · 닦아내기 · 원형 · 블라인드 · 랜덤 — 앞 장면에서 그 사진으로 바뀔 때)를 정하고, 크롭/확장/직접 조절도 동영상과 같습니다.
    (`icon` · `logo` 이름의 그림과 `_` 로 시작하는 파일은 목록에 넣지 않습니다)
- **TV 화면보호기에서 공지 바로 고치기**: 공지 줄 맨 오른쪽의 반투명 **수정 아이콘** → 위쪽 팝업의 숫자패드(3×4)로 **공지 수정 비밀번호 6자리** →
  공지 입력란이 열리고 화면 키보드로 고친 뒤 [저장]. 아이콘·팝업을 눌러도 대시보드로 넘어가지 않습니다.
  비밀번호는 [TV 설정] 탭의 '공지 수정 비밀번호' 또는 TV ⚙ 설정에서 정합니다 (비우면 이 기능을 쓸 수 없음, 5번 틀리면 1분 잠김)
- **[공지사항 편집 HTML 받기]** — 비밀번호를 2번 정하면 `공지사항_편집.html` 이 내려받아집니다. 이 HTML 은 비밀번호를 넣으면 TV 의 지금 공지를 불러와
  고치고 저장할 수 있고, **main/공지.txt 외에는 읽지도 바꾸지도 못합니다**(TV 가 확인). 유출되면 [공지 도구 새로 발급]
- 실적 JSON 4개(생산·sd·fi·plan)와 동영상(1.mp4 2.mp4 …)은 다른 폴더처럼 끌어다 놓거나 자동 업로드 .bat 으로 올리면 됩니다

## 폴더 자동 업로드 .bat (관리자용)

1. 파일 탐색기에서 TV 폴더(예: `원가`)를 고르고 **[자동 업로드 .bat 받기]** → `원가_자동업로드.bat`
2. 이 bat 을 PC 의 **아무 폴더에나 옮겨 두고** 실행 → **bat 이 있는 폴더**(하위 폴더 포함)의 파일을 스캔해서 TV 의 `원가` 폴더로 올립니다
   - 바뀐 파일만 보냅니다. 숨김 파일·`.bat`·`desktop.ini`·`~$` 임시 파일은 올리지 않습니다
   - 작업 스케줄러에 걸 때는 인수 `/q` (끝나고 멈추지 않음). 기록: 이 프로그램 폴더의 `out\sync.log`
   - bat 에는 키·토큰이 없고 이 프로그램 위치만 들어 있습니다. 프로그램 폴더를 옮겼다면 bat 을 다시 받으세요
- 명령줄로는 `python -m tvrelay sync <PC 폴더> --to <TV 폴더>` (`--force` = 같은 파일도 다시 보내기)
- 명령줄: `python -m tvrelay status` (TV 상태), `python -m tvrelay put <PC 파일> <TV 경로>`, `python -m tvrelay pair <연결 코드>`

## 직원용 업로드 도구 (Python 없이, 폴더 전용)

관리자가 폴더마다 **업로드 전용 HTML 한 파일**을 만들어 직원에게 나눠 줍니다. 직원은 Python 없이 Edge·Chrome 에서 열어 씁니다.

1. 관리자: 파일 탐색기에서 폴더(예: `원가`)를 고르고 오른쪽 위 **[업로드 도구 받기]** → **업로드 비밀번호를 2번 입력**
   → `원가_업로드.html` 이 내려받아짐 (처음 한 번은 TV 에 등록되기까지 10~20초, 다음부터는 바로 받음 · 트리에 🔑 표시)
2. 직원: 그 HTML 을 더블클릭 → 파일을 끌어다 놓기 → **업로드 비밀번호 입력** → **[TV 로 올리기]** → TV 에 반영되면 "완료!"와 폴더 파일 목록 표시
   - 폴더 열쇠와 토큰은 업로드 비밀번호로 잠겨 있습니다(PBKDF2 30만 회 + AES-256-GCM). HTML 만 가져가서는 올릴 수 없습니다
   - HTML 과 비밀번호는 따로 전달하세요. 비밀번호를 바꾸려면 [다시 받기]로 새 비밀번호의 HTML 을 받으면 됩니다(같은 열쇠라 옛 HTML 도 계속 동작 — 막으려면 [새로 발급])
   - 올릴 수 있는 형식: **png · js · json · html** / 한 번에 **30MB** 까지 / **같은 이름은 덮어쓰기**
   - 그 폴더(와 하위 폴더)에만 올라가고, 삭제·이름 변경·설정 변경은 할 수 없습니다 (TV 가 확인합니다)
3. HTML 이 유출됐거나 담당자가 바뀌면: 같은 폴더에서 **[새로 발급]** (또는 [연결] 탭의 목록에서 폐기) → 옛 HTML 은 더 이상 동작하지 않습니다
   - [연결] 탭에 직원 도구 전용 GitHub 토큰을 따로 넣어 두면, 도구 토큰만 GitHub 에서 따로 막을 수도 있습니다

> HTML 안에는 관리자 키가 아니라 **비밀번호로 잠근 그 폴더 전용 열쇠**만 들어갑니다. 등록 정보는 이 폴더의 `grants.json` 에 보관됩니다.

## 엑셀 붙여넣기로 JSON 올리기 (관리자 화면 · 직원용 도구 공통)

- 관리자: 탐색기에서 JSON 파일을 고르고 **[엑셀 붙여넣기]** / 직원: 도구 HTML 아래쪽 **엑셀 붙여넣기로 JSON 올리기** 에서 파일 이름 → [양식 불러오기]
- 엑셀에서 표를 복사(Ctrl+C) → 칸에 붙여 넣기(Ctrl+V). 지금 파일의 **양식**을 보고 맞춰 넣습니다.
  - 첫 줄이 머리글(열 이름)이면 이름으로, 머리글이 없으면 **칸 순서대로**
  - 날짜는 파일의 모양(예: `2025.01.03`, `2025.01`)으로 바꿔 넣고, `1,500` · `(300)`(음수) · 엑셀 날짜 숫자도 읽습니다
  - `sd.json` 처럼 `날짜|구분` 키 모음은 앞 칸들이 키, 뒤 칸이 값 (`fi.json` 처럼 값이 {sd, fi} 면 그 칸들)
- 토글: **덮어쓰기**(전체 교체) · **추가하기**(같은 키는 새 값, 표는 아래에 이어 붙임) · **삭제**(붙여 넣은 키/줄을 지움)
- 올리기 전에 표 미리보기와 '새로 n · 바뀜 n · 지움 n → 전체 n' 이 보입니다
- 받아 둔 JSON 은 캐시로 씁니다: 관리자는 PC 의 미리보기 보관함, 직원 도구는 브라우저(localStorage).
  TV 가 알려 주는 버전(sha256)이 같으면 TV 에 묻지 않고 바로 열고, 같은 폴더의 다른 JSON 도 함께 받아 둡니다.
  직원 도구로 JSON 을 읽으려면 TV 앱 1.8.6 이상이 필요합니다 (도구 HTML 은 다시 받아야 이 기능이 보입니다).

- **두 번 누름 · 같은 내용 다시 보내기 방지**: 버튼은 보내는 동안 잠기고, TV 가 아직 받지 않은 같은 내용은 다시 보내지 않습니다
  (관리자: `out/queued.json`, 직원 도구: 브라우저). TV 가 꺼져 있을 때 이어서 붙여 넣으면 **방금 보낸 내용 기준**으로 계산합니다.
## 폴더 안의 파일

| 파일 | 설명 |
|---|---|
| `tvrun.bat`, `tvupload.bat` | 실행 파일 (ASCII 전용 — 한글을 넣지 마세요) |
| `tvrelay/` | 프로그램 (자동 업데이트로 교체됨) |
| `tvrelay.json` | **내 설정·암호키·토큰** (업데이트해도 그대로, 백업 권장) |
| `out/versions.json` | 이 PC 가 올린 파일의 버전 기록 (TV 가 버전을 모를 때 비교용) |
| `tv-backup/` | TV 이름별 백업 (올린 파일 · 설정) — 새 TV 로 옮길 때 사용 |
| `grants.json` | 발급한 직원용 업로드 도구 목록과 폴더별 열쇠 (업데이트해도 그대로) |
| `venv/` · `out/` · `backup/` · `downloads/` | 자동 생성 (가상환경 · 기록·미리보기 · 업데이트 전 백업 · TV 에서 내려받은 파일) |
| `tvrelay/requirements.txt` | 필요한 라이브러리 목록 — 프로그램이 실행할 때 확인·설치 (Windows 는 회사망용 truststore 하나, 휠만 설치) |
